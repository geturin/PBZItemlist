# 地图贴图与楼层示意

默认使用游戏原生美术地图，收集点按游戏 UV 显示。可选分层平面图独立加载二维导航轮廓；它不是完整游戏场景。当前页面仅提供二维视图，保留收集点原始 XYZ，不改变完成判定、铃铛距离或 CSV 坐标。

## 默认地图：轻量游戏贴图

默认地图直接读取图鉴中的图像引用和点位 UV，不请求楼层几何，也不请求 `terrain-low/manifest.json`。

| 图像级别 | 加载方式 | 整套文件规模 |
| --- | --- | ---: |
| 1024 像素预览 | 选择对应地图后保留作底 | 8 张，777,384 字节 |
| 2048 / 4096 / 8192 像素级别 | 根据当前视野与显示尺寸加载 512 像素 WebP 切片 | 2,548 块，119,700,168 字节 |

每张预览约 100 KB；12 个地图分区共用 8 张美术图。7 张原图为 8192×8192，庞镇共用图为 8192×4512。最高级别直接使用原生贴图解码的像素，较低级别统一缩小，并非把旧 2048 图放大；没有额外旋转、镜像或 AI 重绘。最高细节为原生 8K，放大到更高显示倍率不会创造新的图像细节。

预览位于 `public/data/map-images/`，分级切片与清单位于 `public/data/map-images-hi/`。切片按当前视野加载，不一次下载整套金字塔；当前地图最多同时挂载 36 个切片图像节点，离开视野的节点会移除。2,548 块的总量是磁盘／发布资产规模，不是初始下载量，也不是全浏览器缓存预算。

最大单块 WebP 为 96,534 字节。完整 512×512 RGBA 像素本身约 1 MiB，真实浏览器另有解码、缓存和绘制开销；移除节点也不保证缓存立即释放，因此不能由 36 个节点推导浏览器内存上限。源全尺寸 PNG 仅保留在私有分析目录，不随站点发布。

## 可选的分层平面图

楼层数据由游戏导航地面整理而来，按 **5 米高度层**提取并清理二维轮廓。页面使用预处理多边形，不处理整套高密度导航三角形。高度区域由用户手动选择，不随选中物品自动限制附近高度。

这是显示近似：细小碎片、狭缝和轮廓经过清理与简化，楼层面使用代表高度。它不保留原始导航面的全部细节，也不保证台阶、斜坡、洞口或局部连接逐点一致。不能把它当成完整环境模型或当前存档下的通行判定。

楼层清单为 `public/data/terrain-low/manifest.json`；二维轮廓文件有独立内容哈希和计数。实际发布规模以当前清单为准。旧版高密度导航派生网格仍保留在源码 `public/data/terrain/` 供回归比较；当前页面不请求该目录，发布 ZIP 排除它。已停用的 3D 实验代码、依赖及模型同样仅在源码归档，不随站点发布。

当前发布覆盖 **9 个来源世界、12 个原生地图分区**，合计 458 个高度切片：

| 资产 | 当前规模 | gzip 合计 |
| --- | --- | ---: |
| 独立 2D 轮廓 | 255,257 个轮廓点，含闭合点 | 1,128,873 字节 |

这些是二维发布文件的体积与计数，不代表浏览器内存或帧率实测。

| 数据 | 浏览器中的用途 |
| --- | --- |
| 2D 轮廓，`format: 2` | `layers` 的高度范围、分区和多边形环；SVG 按外轮廓与洞填充，不遍历 3D 三角形 |
| `mapFocus` / `focusByBand` | 逻辑地图及高度区域的初始取景提示，不是精确区域边界 |

## 按需加载与内存

```text
默认游戏地图
  → catalog 中的图像引用与 UV
  → 当前地图 1024 预览始终作底
  → 按视野与像素需求选择 2K / 4K / 8K 级别
  → 挂载最多 36 个 512 像素切片图像节点

可选 2D 楼层
  → 独立轮廓文件
  → SVG 矢量路径
```

切换地图或模式时取消或忽略不再需要的结果，释放对应引用。轮廓生成 SVG 路径，拖动和缩放使用父组变换，不重新把全部多边形栅格化到固定大小画布。轮廓放大不出现低分辨率画布的像素块，但简化后的形状仍有精度边界。实际内存回收时间受浏览器控制。页面不初始化 Three.js 或 WebGL，也不下载 3D 模型。

## 地图操作

- 拖动图面平移；滚轮围绕指针位置缩放，最高 32 倍。`+` / `−` 按钮缩放，复位按钮恢复视图。
- 双击放大；触屏单指平移、双指平移及缩放。
- 整个地图区域捕获滚轮，包括标记和地图按钮；达到缩放边界时仍阻止网页滚动。
- 标记图标应用缩放的倒数，保持较小的屏幕尺寸；选中点用定位十字显示准确中心。
- 键盘聚焦地图后，方向键平移，`+` / `−` 缩放，`Home` 复位。
- 选中物品查看详情；高度区域可手动切换，不使用“附近高度”自动过滤。

## 坐标与精度

离线读取导航数据时，轴转换为：

```text
Unreal (X,Y,Z) = (-RecastX,-RecastZ,RecastY)
```

显示资产已经使用 Unreal 世界坐标厘米，浏览器不应再次执行该转换。分层平面图和世界坐标图将 X 向右、Y 向上绘制；原生 Z 用于高度区域，不参与平面坐标的旋转。

物品标记保留自己的原始高度，不吸附到另一层。楼层显示数据的代表高度与轮廓近似不会写回物品坐标。

杀气塔三处铃铛的定点高度核验不能代表全部拾取点都紧贴楼层面；源导航覆盖与显示近似均有边界。

游戏贴图采用游戏 UV；楼层平面使用世界 XY，两者不要求轮廓或朝向逐像素重合。UV 的离线重建与游戏图标避让边界见[地图投影说明](MAP-PROJECTION.md)。

## 场景与数据边界

游戏安装资源中存在 HLOD 等场景资产，但本项目尚无可验证的完整游戏场景导出；它们不是当前网页的显示数据。网页没有导出或加载完整建筑、植被、材质、光照与场景模型。

站点只分发所需的地图预览、细节图和楼层示意，不分发原始 Unreal 包、完整贴图集、完整导航转储、原始投影锚点或私人调查文件。游戏名称和美术内容的权利归各自权利人所有。

本工具不计算路线。游戏的动态门锁、任务条件、跳跃和入口限制不能由这些示意图确定；附近铃铛的直线距离也不代表可步行距离。

校验与测试范围见[测试说明](TESTING.md)。归档的 Three.js 实验不属于当前网页功能；源码仍保留其 MIT 许可证与归属信息。
