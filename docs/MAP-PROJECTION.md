# 地图投影与精度边界

本文说明 1.1.0 引入、v2 继续保留的“游戏地图”UV 模式。v2 默认改为真实导航表面的 2D 地形，并提供 3D；两者的架构与覆盖见[地形说明](TERRAIN.md)。UV 模式的公开数据为逐点 `mapPosition` 和地图画布比例，原生 XYZ、附近铃铛直线距离、CSV 坐标及收集完成判定不变。

## 旧版世界 XY 图为什么与游戏不同

旧版查看器直接将世界 X 画向右、世界 Y 画向上。它能表示世界平面上的相对位置，但游戏使用的是按 `GroupZ` 分组的锚点三角网格，再结合命中高度将世界点映射到地图 UV。同一世界平面方向，在不同三角形里的地图方向和缩放都可能不同；高度也会影响采用哪一层映射。因此换一个全局旋转、翻转或缩放系数，不能完整还原游戏地图。

游戏 UI 随后把 UV 逐轴乘以实际地图画布尺寸，不再额外反转 Y。UV 的左上角是 `(0,0)`，右下角是 `(1,1)`。还原 UV 后也要保留贴图宽高比，否则非正方形地图会被拉伸。

## 从锚点到地图位置

静态本体分析确认的处理链如下。这里说明游戏算法及离线重建方式，不分发原始锚点或网格。

1. 按地图读取锚点，再按锚点的 `GroupZ` 分组。该字段是分组标识，不应直接当成世界高度。
2. 各组用世界 XY 做 Delaunay 三角剖分，三角形顶点保留原始 Z 和对应地图 UV。
3. 按边界边的长度从长到短处理边界三角形。当边界边所对的角大于 90°，且三角形其余两条边都是内部边时，删除该钝角边界三角形；继续处理至无需删除。角度计算后按单精度与 `pi/2` 比较，临界值会影响结果。
4. 对世界点 `(X,Y,Z)`，从 `(X,Y,Z+1000)` 向下发射射线，求与该地图网格的命中。
5. 按命中位置的 Z 从高到低排序，选择第一个满足 `hitZ < Z+200` 的命中；若没有符合这一阈值的命中，使用最后一个、也就是最低的命中。没有命中则不生成投影。
6. 对选中三角形计算重心权重 `w0,w1,w2`，以单精度权重和 UV 做插值：`UV = (UV0*w0 + UV1*w1) + UV2*w2`。
7. 游戏 UI 用 `UV × 地图画布尺寸 × 缩放` 放置图标，平移由整个画布承担。画布宽归一到 4096，高为 `4096 × 贴图高 / 贴图宽`。

本工具在离线预处理中使用 SciPy/Qhull 生成 Delaunay 网格，并重建上述裁切、命中选择与单精度 UV 插值规则。浏览器不生成网格，只读取已经计算好的点位 UV。

当前庞镇、后街、戏梦山庄的画布为 4096×2256，其余有投影定义的地图为 4096×4096。这些是保持真实贴图比例的归一画布尺寸，不是随点位数量变化的边界框。

## 覆盖与界面行为

当前目录共有 698 个收集点和 187 个铃铛参照，其中 646 个收集点、175 个铃铛参照有投影。12 个地图定义带画布信息，11 个分区有可投影的目录点；断魂山定义目前没有目录点。

附加定义 `XueSeSenLin`、`HuanShuShi` 暂无可靠投影，会使用世界坐标图。不要将前者与显示名为“血色森林”的 `FuJiZhiLin` 混淆；`FuJiZhiLin` 已支持投影。

有投影的分区内仍可能存在少量未命中的点。游戏模式暂不绘制这些点，也不会将它们的世界 XY 混进 UV 图；清单会继续保留记录，用户可切换“世界坐标”查看。地图画布固定，不会因筛选类别或只显示未收集点而重新改变比例。

## 尚未证明的精度

当前重建尚未与运行中的游戏逐点比对。Qhull 和游戏的三角剖分实现可能对退化共圆点采用不同连边；边界裁切、重合命中及浮点临界值也可能不同。测试证明的是前端按已生成 UV 的方向和画布比例绘制、以及未校准点的回退行为，不能据此声称与游戏逐像素完全一致。

离线几何还通过了 9 组合成检查，包括独立重心求解、分片映射、叠层命中、200 单位严格阈值和无命中处理。对梅谷湖的重复 XY 锚点做输入重排及首尾去重实验，现有 99 条点位与铃铛结果保持一致；这些检查仍是静态重建的自洽核验。

游戏还会按当前显示图标、缩放和当前铃铛状态自动避让图标。截图中的图标中心可能偏离自然投影点，标记文字也会跟随移动；本工具没有复制这套截图布局。已加载 Actor 的位置变化，也可能使游戏位置与静态表不同。

这两种位置图都不能说明道路、楼层入口或门锁是否可通行。附近铃铛仍以原生世界坐标计算直线距离，不按 UV 距离排序。

## 公开数据范围

发布目录只包含每点的可选 `mapPosition: {X,Y}` 和每地图的 `mapProjection: {method,width,height}`，不包含分析时使用的 7365 个原始锚点、三角网格、地图贴图、完整游戏脚本或解包工具。运行站点无需安装游戏、SciPy 或 Qhull。

字段含义与精简范围见[图鉴数据范围](DATA.md)，前端测试与尚未覆盖的检查见[测试说明](TESTING.md)。
