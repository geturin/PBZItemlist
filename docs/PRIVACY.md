# 存档与访问统计

## 存档只在浏览器内处理

选择的 `.sav` 文件、解码进度、物品筛选和任务分析在当前页面内存中处理，不上传给服务器，也不写回原文件。刷新或清空会话后需重新导入。检查器无需登录，不将存档写入浏览器持久化存储。

网页仍需请求同源 HTML、脚本、图鉴、解码器和按需地形数据。网站另有独立的访问计数脚本；“存档不上传”不表示网站完全没有网络统计。

## 哪些访问会被计数

`analytics.js` 仅在 `https://game.kero.zone` 的四个公开路由工作：`/`、`/en/`、`/phantom-blade-zero/`、`/phantom-blade-zero/en/`。本地运行或部署到其他域名时不发计数请求。

仅加载页面不计数。页面可见时，第一次由用户真实触发的点击／触摸或键盘事件产生一次访问计数，同一次页面加载最多发送一次。脚本事件、识别出的机器人和自动化浏览器不计数；遵守 Do Not Track 和 Global Privacy Control。

这是交互访问量，不能保证识别所有机器人；访客数也是估算值。服务端会接收到 IP 和 User-Agent，用于过滤与会话去重，不能据此宣称完全匿名或不处理 IP。

请求发送到本站 `/stats/count`，使用不带请求体的 POST，仅包含：

- 固定公开页面路径和固定页面标题。
- 如有站外 HTTP(S) 来源，仅保留其 origin（协议、主机及可选端口），不保留路径、搜索参数或片段。

计数不包含存档、文件名、槽位、搜索词、筛选内容、物品状态或应用事件，不携带 Cookie 或 Referer 请求头，也不发送屏幕尺寸。计数失败不阻断工具。普通 HTTP 连接仍会到达本站服务器；服务端日志与 GoatCounter 的处理和保留设置属于部署配置，不能据此声称服务器看不到网络来源信息。

## 当前浏览器停用计数

除浏览器的 DNT／GPC 设置外，可在本站浏览器控制台执行：

```js
localStorage.setItem('game.analytics.exclude', '1');
```

刷新后生效。恢复时删除这个键并再次刷新：

```js
localStorage.removeItem('game.analytics.exclude');
```

这只保存当前浏览器的统计停用偏好，不保存玩家进度。统计后台与存档检查器是独立部分，检查器本身不需要统计后台账号。对应客户端测试见[测试说明](TESTING.md)。
