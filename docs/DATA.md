# 图鉴数据范围

`public/data/catalog.json` 是查看器所需的静态图鉴，不是游戏资源包或玩家存档的转储。公开版本保留地图、13 类收集点、中文名称、坐标、匹配存档所需的游戏编号，以及任务名称和目标文字。

当前目录包含 698 个来源点、187 个铃铛位置参照和 80 项任务元数据。同一物品可能有多个来源点，因此点位数量不等于游戏内按物品编号去重后的完成度分母。附加地图定义、未知名称及缺失坐标仍按待核实处理，不会自动补成确定路线或已证实的领取条件。

## 运行时保留的字段

| 数据 | 保留内容 | 用途 |
| --- | --- | --- |
| 地图、类别 | `id`、`name` | 筛选和中文标签 |
| 收集点 | `id`、`category`、`mapId`、`name`、`location` | 列表、搜索和位置示意图 |
| 判定标识 | `source` 中实际有值的物品、铃铛、场景对象、事件节点及敌群编号 | 与浏览器内解析的存档记录比较 |
| 判定边界 | `gameCounted`、`aggregationParent` | 保留旧花定义的不确定状态及整花父项过滤语义 |
| 获取条件 | `requirements` 的类型、编号、标签及 `relation` | 展示已知关联；区分关联信息与真正的前置条件 |
| 铃铛参照 | 编号、中文名、地图和坐标 | 计算同分区附近铃铛的直线距离 |
| 任务元数据 | 任务编号、中文名、分支编号和目标文字 | 将用户存档中的任务记录转换为可读内容 |
| 局限说明 | `limitations` | 说明不可达性、未知定义和统计口径等边界 |

`source.saveGuid` 和 `source.nodeGuids` 是游戏静态对象、事件的标识，不是用户的 Steam ID，也不包含用户是否拾取或执行过事件的状态。完成状态仅在用户选择存档后，于浏览器内计算。

`source.flowAsset` 用于识别关联流程，不能当作事件节点编号。条件中的 `relation: "associated"` 也不表示该物品有一个尚未满足的前置任务。未知内容应继续显示为待核实。

## 已省去的分析元数据

运行时图鉴无需包含资源文件路径、二进制偏移、原始本地化键、完整反射结构或生成期间的调试信息。因此发布目录可以省去 `provenance`、逐项 `evidence`、`nameKey` 等溯源字段，以及当前界面和判定代码未使用的中间索引。

这里没有附带原始 `.uasset`、`.utoc`、`.ucas`、`.pak` 文件，没有完整全量 Props 表或中文语言包，也没有游戏资源解包脚本、资源包密钥文件、个人存档、个人行走路线或服务器部署记录。

`build_catalog.py` 依赖发布目录之外的本地分析中间文件，不是启动这个静态网站的必要步骤。精简仓库直接使用已生成的图鉴，并以目录校验和功能测试检查记录结构、数量及判定行为，不要求下载游戏解包产物才能运行。

## 第三方解码器源码

`public/vendor/ooz-wasm/` 中的解码器、许可证、构建文件及对应源码属于 GPL 第三方程序依赖。它们用于浏览器内的解压处理，不是解包得到的游戏源数据。精简游戏分析产物时，仍保留对应的第三方源码、许可证与来源说明。

## 检查范围

发布图鉴应检查本机绝对路径、Steam ID、个人存档文件名、账户信息及资源包密钥文件名；同时检查必需编号、条件关系、未知状态和空坐标是否完整保留。

字段精简已用同一份合成进度数据对比：698 条记录的完成状态、判定说明、关联条件、附近铃铛，以及地图与类别汇总结果保持一致。此检查不读取个人存档。
