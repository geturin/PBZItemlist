# 使用指南

打开[影之刃零全收集检查器](https://game.kero.zone/phantom-blade-zero/)，或使用[英文版](https://game.kero.zone/phantom-blade-zero/en/)。[网站首页](https://game.kero.zone/)是游戏工具总入口。

## 导入存档

拖入游戏的 `.sav` 文件，或点击“选择存档”。工具在当前浏览器中读取和分析，不上传文件，也不修改原存档。不导入存档时，也可以浏览物品清单和位置。

导入后，默认选择最近保存的可用栏位。用“存档栏位”切换自动或手动存档；清单、统计和任务记录随之重新计算。比较进度前，请核对保存时间和周目。

当前支持 PBZS 3，文件上限为 40 MiB。读取失败时，请确认所选文件完整并来自支持的游戏版本。刷新页面或清空存档后，需要重新选择文件。

## 查看缺失物品

1. 选择地图和类别，例如铃铛、杀气琥珀或黑石。
2. 按名称、编号或线索搜索。英文界面也支持中文物品名。
3. 勾选“仅未完成 / 待确认”，缩小清单范围。
4. 点击物品或地图标记，展开位置、附近铃铛和收集条件。

| 状态 | 含义 |
| --- | --- |
| 已完成 | 存档存在当前规则可识别的完成记录 |
| 未完成 | 对应存档模块可读取，但没有该项完成记录 |
| 待确认 | 当前记录不足以作出确定判断，请在游戏内核对 |

未导入存档时不会把所有物品标为未完成。搜索和待确认筛选会缩小清单，概览统计仍按当前地图与类别汇总。

部分装备按本周目获得记录判断。钥匙当前数量为零也不一定代表没拿到，可能已经使用；无法区分时保留“待确认”。同一物品可能有多个来源，因此工具的点位比例不等同于游戏总完成度。

## 使用位置图

默认地图显示游戏原生美术贴图，物品按游戏 UV 投影放置。选择地图后保留约 100 KB 的 1024 像素预览作底，放大时按视野加载 2048、4096、8192 三级切片，最高使用原生 8K 细节。切片不会整套预取，同一地图最多挂载 36 块；浏览器缓存由浏览器管理。只浏览游戏地图不会下载楼层几何或地形清单。

可选“分层平面图”以 SVG 矢量轮廓显示楼层关系，按 5 米高度层整理，放大不依赖低分辨率画布，供定位参考。可手动选择高度区域；选中物品不会自动限制附近高度。它不是完整游戏环境，不包括建筑、植被和全部场景细节。当前页面没有 3D 模式。

游戏贴图使用从左上角计算的 UV；楼层示意和“世界坐标”使用原生世界 XYZ。美术地图与世界坐标的轮廓、朝向可能不同，不能把两者直接叠合。详情中的 XYZ、附近铃铛距离和 CSV 坐标不随视图切换而改变。

- 拖动图面平移；滚轮围绕指针位置缩放，也可使用 `+`、`−`，最高 32 倍。复位按钮恢复视图。
- 双击图面放大；触屏可单指拖动、双指平移及缩放。
- 滚轮位于地图、标记或地图按钮上时不会带动网页滚动，达到缩放边界也一样。
- 标记保持较小的屏幕尺寸；选中物品显示定位十字，便于核对准确中心。
- 键盘聚焦地图后，用方向键平移，`+`、`−` 缩放，`Home` 复位。
- 用 `Tab` 选择标记，按 `Enter` 或空格查看详情。
- 部分点尚无可靠投影时，仍可在清单中查看，或切换世界坐标定位。

楼层示意经过轮廓清理和简化，不表示逐点精确的通行面，也不能反映所有动态门锁和任务条件。本工具不提供寻路。附近铃铛按直线距离比较；靠近坐标不代表必然可达或可以领取。覆盖范围与高度坐标见[地形说明](TERRAIN.md)，UV 精度边界见[地图投影说明](MAP-PROJECTION.md)。

物品详情中的“判断依据与数据说明”默认折叠，需要核对时再展开。相关任务不自动视为物品领取前置；没有可靠依据的条件不会被强行判成未满足。

## 查看任务

导入后点击“任务记录”，搜索任务名、分支目标或编号，也可按进行中、已完成、失败或待确认筛选。展开任务可查看记录中的分支。

任务失败不一定意味着相关物品永久错过，未记录的任务也不代表不能触发；请结合游戏内状态核对。

## 导出与清空

“导出 CSV”保存当前筛选结果，包含物品编号、状态与原生坐标。切换语言只影响名称和说明，不改变编号、坐标或判定规则。

“清空存档”移除当前页面中的个人进度，恢复清单浏览。工具不会写回存档，也不提供补齐或修改存档功能。

线上独立的页面访问计数不读取存档或筛选内容；计数范围及停用方法见[隐私说明](PRIVACY.md)。

## 常见问题

### 游戏里已拿到，为什么仍显示未完成？

先核对栏位、保存时间和周目，再展开该条目的判断依据。旧版字段差异、不同物品来源或尚未保存的进度都可能影响结果。

### 为什么英文页仍能看到中文？

英文名称优先使用游戏英文文本。缺少可靠译名的内容保留原文，避免编造名称；中文名称也用于双语搜索。

### 本地运行为什么不能直接双击 HTML？

存档解码需要 WebCrypto，页面使用 ES modules。请通过 HTTPS 或 localhost 访问，按 [README](../README.md#本地运行)启动静态服务器。

### 如何反馈问题？

提供物品编号、游戏版本、所选栏位与游戏内表现即可，方法见[贡献指南](../CONTRIBUTING.md)。无需公开自己的存档或账号信息。
