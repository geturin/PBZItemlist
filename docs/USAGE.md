# 使用指南

打开 [影境拾遗](https://blog.kero.zone/)，或按 [README](../README.md#本地运行) 启动本地静态站点。

## 1. 选择存档

将 `.sav` 文件拖到页面，或点击“选择存档文件”。应用会在当前浏览器中读取并解码文件，列出其中可用的游戏槽位。

当前读取器支持 PBZS 3，单个文件上限为 40 MiB。若提示格式、认证或解压错误，请确认文件完整、格式受支持；不要通过改扩展名将其他文件当作存档导入。

文件选择对话框只负责把你选中的文件交给页面读取。工具不会扫描其他目录，也不会覆盖原文件。无需输入 Steam 账号、密码或其他登录信息。

## 2. 确认槽位与周目

载入后，页面默认选择保存时间最近的可用槽位。使用“当前槽位”下拉框切换自动存档或手动存档。

比较进度前，先核对槽位名称与保存时间。较早的手动槽位可能还没有记录之后获得的物品；不同槽位也可能处于不同周目。

部分装备类别会结合当前周目与获得周目判断。其他周目曾拥有某件装备，不代表当前槽位的本周目收集也已经完成。切换槽位后，清单、统计和任务记录会一并重新计算。

## 3. 理解三种状态

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 已完成 | 存档中存在当前判定规则可识别的完成依据 | 在详情中查看获得、激活或事件记录 |
| 未完成 | 所需模块可读取，但尚无对应完成记录 | 结合位置和实际获取方式继续探索 |
| 待确认 | 模块、标识或可验证逻辑不足以得出结论 | 在游戏内核对，或保留编号反馈问题 |

未载入存档时，页面只用于浏览图鉴，不会把所有点位标成未完成。

钥匙尤其需要结合使用情况判断。当前数量为零不等于从未获得；缺少历史记录时，也无法仅凭“背包里没有”区分未拿、已用和版本差异。此类情况会保留待确认状态。

## 4. 筛选点位

1. 选择“地图分区”，缩小探索范围。
2. 选择“收集类别”，例如铃铛、杀气琥珀或黑石。
3. 使用搜索框查找名称、编号或已收录的线索。
4. 载入存档后，可勾选“仅未收 / 待确认”。

统计以当前地图与类别下的点位为单位。搜索框和“仅未收 / 待确认”主要用于缩小清单，因此列表数量与概览统计可能不同。

需要恢复完整清单时，点击“重置筛选”。

## 5. 使用坐标图与详情

选择一个地图分区，或点击清单中的点位。1.1.0 默认使用“游戏地图”模式，按离线重建的游戏投影方向和画布比例显示位置；横向和纵向百分比均从地图左上角起算。界面没有附带道路底图。

通过图面右上的“游戏地图 / 世界坐标”下拉框切换模式。“世界坐标”显示原生世界 XY 平面；详情始终保留原生 XYZ、完成依据及附近铃铛，CSV 和直线距离不会随模式改变。

当前有 646/698 个收集点和 175/187 个铃铛参照具备投影。少量点尚未校准时，游戏模式会提示数量并暂不绘制这些点；点位仍保留在清单中，可切换世界坐标查看。附加定义 `XueSeSenLin`、`HuanShuShi` 暂无可靠投影，会回退到世界 XY；显示名为“血色森林”的 `FuJiZhiLin` 已支持投影。

- `+` / `−` 按钮缩放，定位按钮复位，拖动图面平移。
- 键盘聚焦坐标图后，方向键平移，`+` / `−` 缩放，`Home` 复位。
- 使用 `Tab` 聚焦标记，按 `Enter` 或空格查看详情。
- Z 为高度参考；铃铛距离和高差仅用于比较相对位置。

**这张图没有道路、层间入口或可达性导航。** 两个点看起来很近，也可能隔着山壁或不同楼层。最近铃铛按直线距离排序，实际路线仍要在游戏内判断。

游戏投影由静态数据离线重建，尚未与运行中的游戏逐点比对；游戏还会为拥挤图标自动避让，因此截图中的图标中心不一定与工具重合。关于旧版世界 XY 图为何与游戏方向不同，以及重建方法的限制，见[地图投影说明](MAP-PROJECTION.md)。

详情中的相关条件只展示已具备依据的内容。若条目没有可靠的入口、前置或奖励领取方式，不能把“到达坐标”理解为“必然能拿到物品”。

## 6. 查看任务记录

载入后，点击文件条上的“任务记录”。可搜索任务名、分支目标或编号，也可按进行中、已完成、失败记录和待确认筛选。

展开任务可查看当前分支、已完成分支以及可展示的目标。这些内容来自存档中的任务状态与图鉴中的任务说明。

**任务记录不代表每项物品的前置条件。** 工具没有把所有任务自动关联到物品，也不会因为某个任务失败就断言相关物品全部永久错过。没有任务记录时，也不等于该任务无法接取。

## 7. 导出和清空

“导出 CSV”会导出当前筛选结果，包括名称、编号、地图、类别、状态、坐标和可用依据。导出后可自行保存或整理；分享前请确认内容符合自己的意愿。

“清空会话”会清除页面中的存档分析结果和任务记录，并回到图鉴浏览状态。刷新页面也会丢失当前会话。需要继续分析时，重新选择存档即可。

## 常见问题

### 为什么游戏已经拿到，工具仍显示未完成？

先确认选择的是最近保存的正确槽位，再检查是否为本周目获得。游戏尚未保存、不同物品来源、旧版字段差异或当前规则覆盖不足，都可能导致结果不同。详情中的完成依据有助于定位原因。

### 为什么点位总数与游戏地图不一样？

工具按目录点位统计；游戏可能按物品编号去重，并以不同类别计算完成度。同一物品多个来源、整花与花瓣、钥匙及主要物品都会影响两种口径的比较。附加定义的地图也可能尚未确认当前可达性。

### 为什么没有显示所有入口和具体路线？

公开版提供游戏地图投影、原生坐标与可验证记录，没有附带整套地图贴图或逐步攻略。坐标只能说明位置，不能代替关卡路线、门锁条件或任务流程。

### 能否直接修改、补齐或写回存档？

不能。工具只读取文件并生成分析结果，不提供存档修改或写回功能。

### 页面为什么要求 HTTPS 或 localhost？

解码器需要浏览器的 WebCrypto 安全上下文；页面还使用 ES modules。请访问线上 HTTPS 站点，或运行本地静态服务器，不要直接以 `file://` 打开页面。
